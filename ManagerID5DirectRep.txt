/*

Write a solution to find managers with at least five direct reports.

Return the result table in any order.

The result format is in the following example.

 

Example 1:

Input: 
Employee table:
+-----+-------+------------+-----------+
| id  | name  | department | managerId |
+-----+-------+------------+-----------+
| 101 | John  | A          | null      |
| 102 | Dan   | A          | 101       |
| 103 | James | A          | 101       |
| 104 | Amy   | A          | 101       |
| 105 | Anne  | A          | 101       |
| 106 | Ron   | B          | 101       |
+-----+-------+------------+-----------+
Output: 
+------+
| name |
+------+
| John |
+------+

Why This Works

ON E1.id = E2.managerId: Correctly links the manager (E1) to their direct reports (E2).

GROUP BY E1.id, E1.name: Groups the rows by manager so you can aggregate their reports. Including E1.id in GROUP BY ensures accuracy even if two managers share the same name.

HAVING COUNT(E2.id) >= 5: Filters the grouped results to only return managers who have 5 or more direct reports.



*/


select E1.name from Employee E1 JOIN Employee E2 on E1.id = E2.managerId
GROUP BY E1.id,E1.name
HAVING COUNT(E2.id) >=5;
