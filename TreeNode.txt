/*

608. Tree Node

Table: Tree

+-------------+------+
| Column Name | Type |
+-------------+------+
| id          | int  |
| p_id        | int  |
+-------------+------+

id is the column with unique values for this table.
Each row of this table contains information about the id of a node and the id of its parent node in a tree.
The given structure is always a valid tree.
 

Each node in the tree can be one of three types:

"Leaf": if the node is a leaf node.
"Root": if the node is the root of the tree.
"Inner": If the node is neither a leaf node nor a root node.
Write a solution to report the type of each node in the tree.

Return the result table in any order.

The result format is in the following example.

Input: 
Tree table:
+----+------+
| id | p_id |
+----+------+
| 1  | null |
| 2  | 1    |
| 3  | 1    |
| 4  | 2    |
| 5  | 2    |
+----+------+


Output: 
+----+-------+
| id | type  |
+----+-------+
| 1  | Root  |
| 2  | Inner |
| 3  | Leaf  |
| 4  | Leaf  |
| 5  | Leaf  |
+----+-------+


Explanation: 
Node 1 is the root node because its parent node is null and it has child nodes 2 and 3.
Node 2 is an inner node because it has parent node 1 and child node 4 and 5.
Nodes 3, 4, and 5 are leaf nodes because they have parent nodes and they do not have child nodes.

*/

==================================================================================================================


select id,
CASE 
WHEN p_id IS NULL THEN 'Root'
WHEN id IN (
    select distinct p_id
    from Tree where p_id is not null
) then 'Inner'
else 'Leaf'
End as type
from Tree order by id;


==================================================================================================================


1. What does END mean?
END tells SQL that the CASE expression is finished.
Think of CASE as an if-elif-else statement in Python.

Just as Python's conditional block ends through indentation, 
SQL's CASE expression ends with END


2. What does AS type mean?
AS type gives a name (alias) to the output column produced by the CASE expression.


Here, type is the column heading for the values returned by the CASE expression.
You could also write END type without AS in Oracle SQL; both are valid.

Remember:
- CASE → Starts the conditional expression.
- WHEN / THEN / ELSE → Define the conditions and results.
- END → Finishes the conditional expression.
- AS type → Names the resulting column type.

==================================================================================================================


Node type	       Rule
==========================================================
Root	           p_id IS NULL
Inner	           Has a parent and has at least one child
Leaf	           Has a parent but has no children


Key concept: A node is an inner node if its id appears in the p_id column of another row.



Remember:
- id = the node itself.
- p_id = the parent of that node.


2. How do we identify an Inner node?
An Inner node is a node that has at least one child.
To find its children, look for rows where its id appears in the p_id column.


Here, p_id = 1 appears twice. That means nodes 2 and 3 are children of node 1.
So, node 1 has children.

Therefore, node 2 has children too.
- Node 1 → Root
- Node 2 → Inner


3. How do we identify a Leaf node?
A Leaf node is a node that has no children.
Let's check node 3.
Does p_id = 3 appear anywhere in the table? No.
That means node 3 has no children, so it is a Leaf.
Similarly:
- Node 4 → No row has p_id = 4 → Leaf
- Node 5 → No row has p_id = 5 → Leaf
