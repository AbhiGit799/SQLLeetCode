NVL is an Oracle PL/SQL function that replaces a NULL value with a specified alternate value.

Syntax
=======
NVL(string1, replace_with)

string1: The value, column, or expression to check for NULL.

replace_with: The fallback value returned if string1 is NULL. If string1 is not NULL, NVL simply returns string1.


Example
=======
Suppose you have an Employees table where some employees do not receive a commission (commission_pct is NULL):

employee_id       salary         commission_pct
101               5000            0.10
102               6000            NULL


If you calculate total compensation without handling NULL, any math operations involving NULL result in NULL:

-- Returns NULL for employee 102 because 6000 + (6000 * NULL) = NULL
SELECT 
    employee_id, 
    salary + (salary * commission_pct) AS total_salary
FROM Employees;


Using NVL allows you to replace NULL with 0:
********************************************
SELECT 
    employee_id, 
    salary + (salary * NVL(commission_pct, 0)) AS total_salary
FROM Employees;

Result:
=======
employee_id        total_salary
101                  5500
102                  6000


Key Rule: 
==========
Both parameters must have compatible data types. 
If string1 is a character type, replace_with must also be compatible with character data; if it is numeric, replace_with must be numeric.
