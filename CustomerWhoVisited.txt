/*

1581. Customer Who Visited but Did Not Make Any Transactions

Write a solution to find the IDs of the users who visited without making any transactions and the number of times they made these types of visits.

Return the result table sorted in any order.

The result format is in the following example.

 

Example 1:

Input: 
Visits
+----------+-------------+
| visit_id | customer_id |
+----------+-------------+
| 1        | 23          |
| 2        | 9           |
| 4        | 30          |
| 5        | 54          |
| 6        | 96          |
| 7        | 54          |
| 8        | 54          |
+----------+-------------+
Transactions
+----------------+----------+--------+
| transaction_id | visit_id | amount |
+----------------+----------+--------+
| 2              | 5        | 310    |
| 3              | 5        | 300    |
| 9              | 5        | 200    |
| 12             | 1        | 910    |
| 13             | 2        | 970    |
+----------------+----------+--------+
Output: 
+-------------+----------------+
| customer_id | count_no_trans |
+-------------+----------------+
| 54          | 2              |
| 30          | 1              |
| 96          | 1              |
+-------------+----------------+
Explanation: 
Customer with id = 23 visited the mall once and made one transaction during the visit with id = 12.
Customer with id = 9 visited the mall once and made one transaction during the visit with id = 13.
Customer with id = 30 visited the mall once and did not make any transactions.
Customer with id = 54 visited the mall three times. During 2 visits they did not make any transactions, and during one visit they made 3 transactions.
Customer with id = 96 visited the mall once and did not make any transactions.
As we can see, users with IDs 30 and 96 visited the mall one time without making any transactions. Also, user 54 visited the mall twice and did not make any transactions.


Why we use group by?

We use GROUP BY in SQL to collapse multiple rows into summary rows based on shared values in one or more columns.

Without GROUP BY, aggregate functions like COUNT(), SUM(), AVG(), MIN(), and MAX() calculate a single result for the entire table. With GROUP BY, those calculations are calculated per group.

The Core Purpose: Data Aggregation
Think of GROUP BY like sorting a deck of cards into suits (Hearts, Spades, Diamonds, Clubs) before counting how many cards are in each suit.

RAW DATA (Visits Table)

RAW DATA (Visits Table)
+----------+-------------+
| visit_id | customer_id |
+----------+-------------+
|    1     |     23      |  <-- Customer 23
|    2     |     23      |  <-- Customer 23
|    3     |     45      |  <-- Customer 45
|    4     |     23      |  <-- Customer 23
+----------+-------------+

GROUP BY customer_id
+-------------+------------------+
| customer_id | COUNT(visit_id)  |
+-------------+------------------+
|     23      |        3         |  <-- Collapsed 3 rows into 1
|     45      |        1         |  <-- Collapsed 1 row into 1
+-------------+------------------+

Common Use Cases
==================
Counting per category: Finding how many visits each customer made (COUNT).

Financial totals: Calculating total sales per department or per month (SUM).

Averages: Finding the average test score per class (AVG).

Extremes: Finding the highest order value per country (MAX).

Whether you use GROUP BY depends entirely on whether you want a single answer for the entire table or 
separate answers for different categories/groups.


+------------------------------------------+-------------------+--------------------------------------------------------+
| What do you want?                        | Need GROUP BY?    | Example Query                                          |
+----------------------------------------+-------------------+--------------------------------------------------------+
| One overall result for all rows          | No                | SELECT COUNT(*) FROM Users;                            |
| Results broken down by a specific column | Yes               | SELECT country, COUNT(*) FROM Users GROUP BY country;  |
+----------------------------------------+-------------------+--------------------------------------------------------+



*/

/* Write your PL/SQL query statement below */

SELECT 
    v.customer_id, 
    COUNT(v.visit_id) AS count_no_trans
FROM Visits v
LEFT JOIN Transactions t 
    ON v.visit_id = t.visit_id
WHERE t.transaction_id IS NULL
GROUP BY v.customer_id;
