
The LISTAGG() function in Oracle SQL is a powerful built-in tool used to 
transform data from multiple rows into a single string of delimited values. 
It is primarily used to denormalize row-level data into a clean, 
comma-separated (or otherwise separated) list for reporting.


1. Basic Syntax
================
The syntax requires the WITHIN GROUP clause to specify how the aggregated string should be ordered:

LISTAGG(expression, 'delimiter') WITHIN GROUP (ORDER BY column_name)

expression: The column or value you want to combine.

'delimiter': The character or string used to separate the values (e.g., ',' or ', '). If omitted, it defaults to NULL.

WITHIN GROUP (ORDER BY ...): Mandatory. Determines the alphabetical or numerical sorting order of the elements inside the final string.

=================================================================================================================================================================

SELECT department_id,
       LISTAGG(FIRST_NAME, ', ') WITHIN GROUP (ORDER BY FIRST_NAME) AS employee_list
FROM HR.EMPLOYEES
GROUP BY department_id;
