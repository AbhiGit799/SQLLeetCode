Find the names of the customer that are either:

referred by any customer with id != 2.
not referred by any customer.
Return the result table in any order.

The result format is in the following example.

 

Example 1:

Input: 
Customer table:
+----+------+------------+
| id | name | referee_id |
+----+------+------------+
| 1  | Will | null       |
| 2  | Jane | null       |
| 3  | Alex | 2          |
| 4  | Bill | null       |
| 5  | Zack | 1          |
| 6  | Mark | 2          |
+----+------+------------+
Output: 
+------+
| name |
+------+
| Will |
| Jane |
| Bill |
| Zack |
+------+


===============================================================================================================================================================

Ans =>

SELECT name FROM Customer WHERE referee_id IS NULL
OR referee_id NOT IN (2);


Problem
=======
NOT IN (2) is a bit clunky.
NOT IN can behave unexpectedly if the column contains NULL values.
The optimizer may not handle it as efficiently as other operators.


Optimized Query
===============
SELECT name FROM Customer WHERE referee_id IS NULL OR referee_id <> 2;


🚀 Key Takeaways
==================
Use <> operator instead of NOT IN for single values.
Always handle NULL values explicitly.
This query is now cleaner, faster, and easier to understand.
